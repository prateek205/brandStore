# 🛍️ Brand Store Website (HTML & CSS)

A responsive **Brand Store / E-commerce Landing Page** built using **pure HTML and CSS only**.
This project represents an online shopping website interface where users can browse brands, view products, and explore categories.

The aim of this project is to practice **real-world website layout design, flexbox, product cards, navigation bars, and responsive UI styling** without using JavaScript.

---

## 🚀 Live Demo

### Live Demo: https://staticwebsitebrandstoreprateek.netlify.app/

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Google Fonts
- Font Awesome Icons

---

## 📌 Features

- Sticky Navigation Bar
- Hero Banner Section
- Featured Brands Section
- Product Cards with Price
- Category Section
- Hover Effects on Products
- Call-to-Action Buttons
- Footer with Social Links
- Fully Responsive Layout
